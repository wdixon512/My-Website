This is a **sample post**. It only shows up in `npm run dev`, because `draft: true` hides it in production builds.

## How to write a post

1. Add a `.md` file to `content/blog/`. The file name becomes the URL (`/blog/<file-name>`).
2. Fill in `title`, `date`, and `summary` in the front matter at the top.
3. Set `draft: false` (or delete the line) when it's ready to publish.

Delete this file once the first real post is in.
